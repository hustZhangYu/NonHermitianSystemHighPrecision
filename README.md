# high-precision-Non-Hermitian-System
Use mpmath to calculate the properties of Non-Hermitiain systems . The codes includes the study about the eigenvalues, eigenstatets and quantum dynamics.

## Layout and setup

Research scripts and local helpers are in `Non-Hermitian-Critical-Edge/`.
Install the source-imported dependencies with
`python -m pip install -r requirements.txt` in an isolated environment.
The original environment versions are unknown; this file is not a lock.
Run bounded checks from the repository root with
`python -m unittest discover -s tests`.

`data_io.py` shares CSV loading and full complex-literal parsing, including
scientific notation. Parsed values remain Python `complex` values rather
than arbitrary-precision numbers. `dynamics.py` shares the existing initial
state and time-evolution loop. The two legacy dynamics scripts retain their
respective two-value and three-value return interfaces.

## Before reproducing a calculation

Inspect the selected script's system size, time grid, worker count, data
paths and output filenames. Several scripts contain machine-specific CSV
paths, and running an entry point may launch a large eigensolver or process
pool. The optional `NHPlot.py` helper is absent from this tree; the two
eigenvalue plotting routes calling `PlotIPR` still require the original
helper. Its scientific plotting definition has not been invented here.

The seven legacy `mp.dps` assignments following `import mpmath as mp`
now use `mp.mp.dps`, so their recorded 200/300/400 decimal-digit settings
actually configure the active mpmath context. This bug fix can change
regenerated numerical results relative to runs using the default context.
Existing datasets and figures are preserved. Record the active precision
when reproducing a calculation; imports share the global mpmath context.
Hamiltonians, eigenvalue ordering and time-grid conventions are unchanged.
The Hamiltonian boundary-term convention and odd-size mosaic pairing also
remain as originally implemented. Full research calculations and figures
have not been regenerated by the bounded checks.
